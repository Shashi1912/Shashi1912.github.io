Flagship side project · fully offline AI

Automation Engine: the tester that works the app itself

Point it at any Windows desktop application and it tests like a human: it reads the screen through UI Automation and OCR, chooses one action per turn, predicts what should happen, then checks that it did. Deterministic rules and caches decide first; a local LLM is consulted only when code can't decide. It records flows, replays them as parameterized exercises, watches memory trends for leaks, and writes self-contained HTML reports with evidence for every incident.

Selected investigations

Inside the test run.

01   Simulator replay accuracy

During simulator testing, the target-zoom replay showed a mismatch between the point of aim and the displayed impact.

Reproduction path · Record a session, capture the live aim and impact, then replay the same event at the same range. Compare the two frames and note the replay camera position.

Evidence · The mismatch was observed. Fix verification is pending.

02   Windows desktop automation

Selected Winium tests located controls in the 32-bit build and raised NoSuchElementException in the 64-bit build.

Investigation · Run the same Java test against both builds, inspect the accessibility tree and compare the locator, window context and timing for the first missing control.

Evidence · The difference was observed for a subset of controls. The underlying cause remains open.

03   Loan API error handling

In a practice loan application, a malformed loan ID returned HTTP 404. An EMI payment using a valid loan ID and insufficient funds returned HTTP 409.

Regression design · Assert the HTTP status and application error code independently. Compare the balance and EMI state before and after each rejected request.

04   Side project: an agent that tests desktop apps

I am building an offline AI engine that works an unfamiliar Windows application the way a tester would: perceive the UI, choose one action, verify a falsifiable post-condition, remember what changed.

Approach · Python, Windows UI Automation and OCR for perception; a code-first decision ladder where rules and caches act before a local LLM is consulted; safety enforced in code, never by prompt.

A smaller companion, AIAgent on GitHub, generates test cases and bug reports to Excel, PDF and Word.
